Privacy limits

A browser app cannot reliably prevent screenshots, screen recording, cameras, developer tools, or copying. The hide-chat control only obscures this page. Do not treat it as leak-proof protection.

Private-room encryption protects message contents in transit when every participant uses the same passphrase, but the relay still sees metadata such as room identifiers, message sizes, timing, and display names. This prototype has no accounts, moderation, abuse reporting, or audited cryptographic review.
